# Prisma Cursos - Plataforma Institucional

> Projeto trainee desenvolvido em grupo para a criação da presença digital oficial do **Prisma Cursos**, combinando tecnologia, design e gestão em um modelo de ensino híbrido.

---

## Sobre o Projeto
A **Prisma Cursos** é um instituto de educação profissionalizante voltado tanto para jovens em busca do primeiro emprego, quanto para profissionais adultos em transição de carreira. 

Este repositório comporta o código-fonte do site institucional desenvolvido para solucionar a ausência de um canal digital centralizado, aumentando a credibilidade da instituição e facilitando a captação de novos alunos.

## Problemas de Negócio Resolvidos
O projeto foi estruturado para solucionar os seguintes desafios da instituição:
* Ausência de um canal digital claro para apresentar o instituto, proposta e valores.
* Falta de uma vitrine organizada para expor os cursos e o modelo híbrido de ensino.
* Necessidade de exibir evidências públicas de resultados para gerar confiança.
* Inexistência de um canal de contato estruturado.

---

## Objetivos da Solução
* Apresentar de forma clara e organizada as informações institucionais.
* Divulgar os cursos nas áreas de **tecnologia, design e gestão**, destacando o formato híbrido (presencial + online).
* Exibir depoimentos de alunos e resultados para gerar prova social.
* Facilitar o contato direto com potenciais alunos por meio de formulários e canais acessíveis.

---

## Tecnologias Utilizadas
O projeto foi desenvolvido utilizando as seguintes tecnologias para desenvovimento web, garantindo alta compatibilidade e performance:
* **HTML5:** Estruturação das páginas.
* **CSS3:** Estilização visual baseada na identidade da marca e design responsivo.
* **JavaScript:** Interatividade e comportamento dinâmico do site.
* **Figma:** Ferramenta utilizada para a prototipagem prévia das telas (Desktop, Tablet e Mobile).
